# ClipX 0.4

Native macOS clipboard shelf + automatic Pastes.io upload.

## New UI
- Paste-inspired horizontal clipboard shelf
- Text, links and image cards
- Search
- Click a card to copy it back to the clipboard
- Menu-bar control
- Local history up to 50 items
- Text is automatically uploaded to Pastes.io when an API key is configured
- Images remain local for now

## Build
```bash
chmod +x build.sh
./build.sh
```
